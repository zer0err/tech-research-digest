# 首套课程地图：从零开发资料问答 AI 应用

日期：2026-10-28。状态：本轮实施蓝图，不是完成证明。

本套沿用三份零基础试验课，扩展为一个 **18 单元**的完整系列，每课预计约 2 小时，总投入约 36 小时仅为安排估计。18 课是实施选择；用户的约束是每系列不超过 30 单元，没有最低课数。课程全部本地制作与验证后，再经用户确认一次性公开，不逐日解锁。AI 生态工具目录暂缓。

## 1. 最终成果和能力边界

读者完成一个本机可运行的中文资料问答应用：维护资料 → 检索证据 → 调用模型 → 显示带引用的回答 → 处理没资料、坏输入、网络失败和额度限制 → 运行自动检查与小型评测。可以将虚构说明书替换成自己合法持有且不敏感的资料。

“完成 AI 应用”不等于从头训练大模型，也不等于生产级公网部署。本系列不承诺覆盖全部 AI、微调、数学基础或智能硬件；以后可另做独立系列。最终必须存在真实模型适配路径，离线假响应只能帮助无密钥读者练习与测试，不能冒充真实模型实测。

## 2. 统一学习环境与项目连续性

- Python 3.12 + uv，延续前三课，不突然切换 Node、Notebook 或另一套环境。
- 优先标准库，避免为了展示技术堆叠增加框架；确需第三方依赖时锁定并统一说明。
- 学习目录沿用 `vorasio-lesson-01`。每课明确“保留/新增/替换哪些文件”，提供完整最终文件，不让小白自行拼接散落片段。
- 四条中文虚构说明是前三课成果；后续增加稳定资料 ID、来源和分块信息时给出完整迁移数据，旧文件保留备份，不能静默变换字段。
- macOS 已有执行证据；Windows 命令另列，并以实际验证情况标注。教学网页服务默认只监听本机，不在共享网络开放。
- 真实模型 Key 只在本机进程环境；不放前端、URL、截图、输出日志或仓库。课程作者模型与读者调用的模型分别标识。

## 3. 逐课地图与最低验收

每课具体分钟分配由作者按内容调整，不以“120 分钟”伪装真实学习者计时。下表每课列出至少两项不同目标的必需练习；正文若另有独立练习，也必须进入末尾清单。练习 ID 应稳定，示例可采用 `ex-01`、`ex-02`，由系列/单元 ID 组成完整唯一键。

| 单元 | 标题与先修 | 可运行交付物 | 独立练习与可核验标准 |
|---|---|---|---|
| 01 | 从零运行你的第一个 Python 程序；无先修 | 沿用现有 `hello.py`、`manual.py` | 练习 1：亲手保存并运行脚本，输出与正文一致；练习 2：增加第三条资料并修改断言，正确数据通过，错误数量会失败。终端命令与文件代码区分清楚。 |
| 02 | 把资料保存到文件，再读回来；完成 01 | 沿用 `documents.json`、`read_manual.py` | 练习 1：修改第三条标题后读回新值；练习 2：增加“温度测量”形成四条并更新验收。JSON 解析通过，从其它工作目录启动也读取脚本旁的文件。 |
| 03 | 让电脑逐条查找说明；完成 02 | 沿用 `search_manual.py` | 练习 1：测试有匹配、无匹配和多匹配；练习 2：处理空白输入与 USB 大小写。计数在循环后输出，空查询不返回全部资料，原文大小写不被修改。 |
| 04 | 用函数整理程序；完成 03 | 可导入的 `manual_core.py` 与薄命令行入口 | 练习 1：把读取和查找各写成函数并调用；练习 2：向函数传入另一份小资料而非依赖全局变量。导入模块不自动读输入或运行程序，旧三课查询结果保持一致。 |
| 05 | 验证资料并读懂错误；完成 04 | 数据验证函数、带可理解错误提示的读取入口 | 练习 1：为四条资料加入稳定 ID 并验证重复/空字段；练习 2：分别制造不存在文件与错误 JSON，再修好。错误明确、不把异常吞成空列表，不意外覆盖原资料。 |
| 06 | 给自己的程序写测试；完成 05 | `unittest` 测试文件与固定夹具 | 练习 1：新增一条正例和一条负例；练习 2：故意改坏查询/数量断言，确认测试失败后恢复。测试隔离于读者真实资料，重新运行结果一致。 |
| 07 | 从文件走向 HTTP；完成 06 | 本机 HTTP 教学服务与请求客户端 | 练习 1：发送请求并解释 URL、方法、状态码、JSON；练习 2：请求错误路径并处理非成功状态。明确两个终端、启动/停止方式，客户端有超时，不访问未说明的外部地址。 |
| 08 | 第一次接入模型 API；完成 07 | 模型客户端接口、离线适配器、可配置真实适配器 | 练习 1：用固定响应核对消息结构及解析；练习 2：配置或检查真实 API 路径，明确实际是否联网。无 Key 时解释原因并不发请求；Key 不进日志；真实输出用结构验收，不伪造逐字固定结果。 |
| 09 | 让回答遵守结构；完成 08 | 结构化答案解析与验证器 | 练习 1：验证包含答案、引用 ID 的 JSON；练习 2：输入坏 JSON、缺字段和错误类型，展示失败提示。禁止 `eval`，不把“提示模型输出 JSON”当作可靠校验。 |
| 10 | 管理对话与上下文；完成 09 | 有限长度、内存内的对话状态 | 练习 1：连续两轮问题保留所需上下文；练习 2：清空/超过长度时按明确规则截断。用户能重置会话；估计字符长度不冒称准确 token 数，不保存敏感对话到学习进度。 |
| 11 | 整理自己的资料并分块；完成 10 | 纯文本导入与稳定 chunk ID/来源映射 | 练习 1：把一篇原创中文文本拆成多块；练习 2：调整边界并验证无意丢字/重复与来源追溯。给出完整数据迁移，空文档有提示，不顺带引入 PDF/OCR 复杂依赖。 |
| 12 | 让检索结果更相关；完成 11 | 确定性排序、Top-k、结果来源输出 | 练习 1：设计区分前几条结果的查询并核对排序；练习 2：构造同义词失配说明限制。中文处理规则清楚，分数并非概率；当前词面方法不冒称语义向量检索。 |
| 13 | 把证据交给模型再回答；完成 12 | 端到端资料问答管线与引用显示 | 练习 1：回答可在资料定位的问题并核对引用；练习 2：问资料外问题或加入“忽略规则”资料，检查拒答/不执行边界。引用 ID 必须来自本次证据，外部文本仅作数据；不声称消灭幻觉。 |
| 14 | 评测回答，记录坏例；完成 13 | 小型评测集、确定性指标与人工可核查报告 | 练习 1：加入未参与调参的测试问题；练习 2：记录检索命中但回答仍不支持的坏例。分开检索与回答指标，分母口径清楚；不拿有限夹具通过率宣传泛化准确率。 |
| 15 | 给应用加一个本机网页；完成 14 | 简单 HTML 界面与本机 Python 后端 | 练习 1：通过网页提问并显示引用；练习 2：空输入、错误响应仍有清晰反馈。前端不含 Key，模型只在后端调用；对输出安全显示，不把模型字符串作为 HTML 执行。 |
| 16 | 控制费用与失败风险；完成 15 | 请求预算、有限重试、输入上限与日志脱敏 | 练习 1：用假服务重现 429/超时并确认有限重试；练习 2：超长问题或达到预算时停止新调用。费用规则需回官方资料核验，不保证永远免费；不开无限重试，不静默切换付费服务。 |
| 17 | 整理成可交付项目；完成 16 | 项目说明、配置样例、启动/停止步骤、完整测试 | 练习 1：在干净目录按说明重建运行；练习 2：检查配置缺失、端口占用、无 Key 的排错路径。只含虚构资料和空配置；无 Key 泄露；本机开发服务与生产公网服务明确区分。 |
| 18 | 毕业项目：更换资料独立完成应用；完成 17 | 全套应用、原创新资料集、验收报告和学习总结 | 练习 1：在合法无敏感数据的新主题上导入、检索、问答、展示引用；练习 2：提交至少一个失败案例与修正测试。完整运行前后自测通过，说明真实模型验证范围，能解释配置/证据/模型/页面四部分责任。 |

## 4. 每篇必须通过的共同验收

1. **零基础可跟做**：写明起点、学习目标、先修链接、文件树变化、保存位置、完整文件、运行位置及命令；新概念先解释再用。不能只贴局部 diff 或抽象段落。
2. **结果可核验**：确定性程序提供精确预期输出及相应自动测试；模型输出说明变动范围，以结构和证据验收。测试脚本应从正文提取或与正文最终文件校验一致，避免验证的是另一份代码。
3. **练习可完成**：题目、提示、完整参考答案、失败示例、验收方式齐全。必需练习有唯一 ID 与文末独立勾选，单元汇总来自练习状态；不能自动替读者打勾。
4. **环境连续**：本课最终状态是下一课起点。迁移文件格式或目录时完整列出前后差异及修复步骤，不能丢掉前三课成果。运行中不需要未讲解的包或账号。
5. **来源有据**：记录采用的书面课程/官方文档、访问日期、可用版本与许可；复制的许可材料保留版权。来源事实、原创解释、推导、尚未验证结论分别说明。
6. **练习有区别**：对照已采用上游课程及本系列练习，说明该课独立目标、数据或约束；不靠只改标题来“去重”。不做全网绝不重复的承诺。
7. **验证诚实**：记录真实执行环境与结果、AI 作者/自查信息；macOS/Windows、离线替身/真实接口分开标注。无证据不写“已验证”。AI 自查不是专家审稿。
8. **安全可理解**：明确安装联网、文件写入、模型调用的边界；不提供不必要破坏性命令，不自动付费或公开服务，不输出密钥。教学安全措施只说明覆盖的威胁，不宣称生产级绝对安全。
9. **阅读完整**：正文标题下结构化列出环境、来源、AI 与验证摘要；代码与输出区分，移动端无整页溢出，目录、前后课、练习进度可用。
10. **不提前发布**：所有正文、配套程序和证据先在本地完成；用户确认公开前不提交课程正文、不部署、不发 Telegram。

## 5. 总体完工判定

必须同时满足：18 篇完整正文；可从第 1 课走到第 18 课的项目快照/文件；全部必需练习及答案；固定环境；资料与许可记录；正文代码一致性检查和端到端测试；真实模型路径及如实记录的验证范围；逐练习本地进度；移动端/无存储降级；本地预览与最终发布清单。

仅增加目录、标题、测试用元数据、三个示范单元、离线假模型或进度 UI 均不算整套完成。存在未完成/未验证项时列出具体项目，不用“阶段已完成”替代总体状态。
