学完要交付什么

在第七课建立的 vorasio-assistant 项目中新增 src/manual_assistant/model.py、ask_model.py 和测试。程序使用统一的 generate() 接口：测试传入 FakeModel，真实运行传入 OpenAIModel。这样离线测试稳定、免费，真实接口仍可替换。

一、先理解一次请求（0–20 分钟）

模型 API 是网络服务。程序发送模型名、指令和输入，服务返回文字；账户权限、可用模型和费用由服务商决定。成功调用只能证明接口在当时可用，不能证明回答正确。

本课采用 OpenAI Python SDK 的 responses.create 形状。OpenAI 官方文档把 Responses API 作为主要文本生成接口，并建议密钥来自环境变量；Groq 的兼容接口也提供 Responses 路径，但具体支持项与模型需查对应服务商当前文档。课程把地址、密钥、模型都放在配置中，不假设所有服务完全等价。

六、排错和验收（110–120 分钟）

现象 处理
缺少 AI_API_KEY 变量没有设置在运行命令所在的同一终端
401/认证错误 密钥无效或发给了错误服务地址；不要反复尝试
404/模型不存在 模型 ID 或接口能力不匹配，回到官方模型列表
429 达到账户速率或额度限制，按响应信息等待，不写无限重试
连接错误 检查官方状态、网络和 AI_BASE_URL，不要关闭 TLS 验证
测试产生费用 自动测试必须传 FakeModel，不能在测试导入时创建真实客户端

完成标准：离线输出精确通过；能说明真实输出为什么不固定；能证明源码和屏幕没有密钥；能指出替身测试不证明真实模型质量。
