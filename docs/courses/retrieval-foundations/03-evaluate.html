六、排错与验收（110–120 分钟）

现象 原因与修正
IndentationError 缩进层级不对，按完整代码使用空格
SyntaxError 指向 for 或 if 检查末尾是否缺冒号
程序停住了 很可能在等 input，输入关键词并按回车
每条都显示“没找到” 把最终 matches 判断移出 for 循环

输入“怎么供电”没结果 当前只是连续文字匹配，不理解同义表达

不要把“没有找到”理解成资料中绝对没有答案。它可能只是措辞不同。输入“设备为什么不能充电”也不会自动抽取关键词，因为程序把整句话当作一段文字搜索。
