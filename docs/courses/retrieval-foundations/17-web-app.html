服务端只记录错误类名，不打印异常全文、请求正文或密钥。MAX_CONTENT_LENGTH 把请求体限制为 4096 字节，超过时 Flask 返回 413。这个上限与问题的 300 字符限制不同。

@app.get("/") 把浏览器首页地址交给紧接着的 index()；@app.post("/api/ask") 把提问请求交给 ask()，这叫路由。jsonify 把 Python 字典变成 JSON 响应；return ..., 400 同时指定错误状态码。create_app 负责组装应用；最后的启动文件负责监听端口。model=None 表示调用者不传模型时使用离线替身，导入这个模块本身不会启动网页。

四、运行与验证（85–100 分钟）

终端应显示监听 http://127.0.0.1:5000。浏览器打开这个地址，输入“如何充电？”，应看到固定离线回答和 battery-001。输入“火星岩石成分是什么？”，应看到“根据现有资料无法确定。”且来源为“无”。按 Control+C 停止。

不要把这一结果写成“真实 AI 已验证”；页面当前使用 DemoModel。再输入“月球上能使用吗？”，你会看到错误相关的设备摘录，这重现第十六课的局限。提示词没有被离线替身理解，引用校验也不能阻止语义误答。第十二课的对话窗口是独立练习，本网页每次只处理当前问题，尚未接入多轮记忆。

五、原创练习：加载与错误状态（100–115 分钟）

完整页面已包含三种状态：空输入提示、正在查找…、捕获错误，并在 finally 恢复按钮。练习要求你暂时把请求地址改成 /api/missing：页面应显示错误而不是永久停在加载状态；确认后改回 /api/ask。

六、排错与验收（115–120 分钟）

问题 检查
浏览器打不开 服务是否仍运行，地址是否为 127.0.0.1:5000
模板找不到 templates/index.html 是否在项目根目录下的 templates 文件夹
页面一直加载 finally 是否恢复按钮；查看浏览器网络错误

完成标准：充电、无答案和坏请求三条路径均正确；能说明密钥为什么不能放在网页 JavaScript 中。
