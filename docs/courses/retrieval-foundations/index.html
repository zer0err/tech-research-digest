面向完全小白的 18 课闭环路线：从第一行 Python 代码出发，逐步完成数据校验、测试、模型 API、结构化输出、检索、引用、评测和本地网页应用。

    让电脑逐条查找说明

  4. 04
    把查找步骤装进函数

  5. 05
    挡住损坏和缺字段的数据

  9. 09
    第一次调用模型 API

    以可替换客户端调用真实模型，并用离线替身保证测试不花费额度。

  10. 10
    写出可检查的提示词

    让模型返回可验证的 JSON

    解析并校验模型输出，错误时明确失败而非猜测补全。
