四、排错与验收（110–120 分钟）

现象 原因
单引号 JSON 解析失败 JSON 字符串和字段名必须用双引号
True 解析失败 JSON 使用小写 true，Python 显示时才是 True
引用明明存在却被拒绝 allowed_ids 应来自本次实际检索片段，不是全库随意编号
想用正则截取 JSON 不要；应让输出合同明确，并用 JSON 解析器检查完整字符串
