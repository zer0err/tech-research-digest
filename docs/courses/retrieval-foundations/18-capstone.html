五、原创练习：从空目录复现并演示（105–115 分钟）

请找一个没有参与开发的人，仅给他 README，让他完成：安装、测试、启动、提问、停止。观察他在哪里卡住，只修 README 或产品，不在旁边口头补隐藏步骤。记录一条失败和修复；如果一次成功，也记录用时和环境。

你的演示脚本应只有三问：

  1. “如何充电？”——显示答案和 battery-001；
  2. “如何联网？”——显示答案和 network-001；
  3. “火星岩石成分是什么？”——明确拒答且不调用模型。

第三问只验证无词项命中的早退。第十六课“月球上能使用吗？”仍会误命中，必须保留为已知失败，不能据三问演示声称所有无答案问题都能拒答。

三问分别覆盖有依据的两类资料和无依据边界，不用重复前课练习。

六、排错与发布前安全表（115–120 分钟）

如果干净目录无法安装，先核对 Python 3.12、uv.lock 与当前 pyproject.toml 是否来自同一版本；如果测试通过但网页失败，单独检查模板路径与 5000 端口；如果离线演示正常而真实 API 失败，保留错误类型与请求 ID，回到服务商文档核对账户、模型和限额，不删除 TLS 校验，也不把密钥贴进日志。

项目 必须满足
密钥 只在服务端环境变量，已确认未提交
网络 本地默认 127.0.0.1；公开前另做认证、HTTPS、生产服务器与网关限流
输入 类型、空值和长度均检查
输出 JSON 合同与引用白名单均检查，网页用 textContent
依赖 uv.lock 固定，漏洞与许可需持续维护
数据 虚构说明与真实资料明确区分，来源可回查
质量 离线测试、评测、真实接口记录分别呈现
