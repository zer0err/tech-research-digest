这里的 path 是文件路径。load_documents 负责读取并解析 JSON；find_documents 不关心文件在哪里，只接收已经读好的列表。这叫“职责分开”。results 是列表，找到一条就用 append 加进去。len(results) 得到条数。f"{query}：{len(results)} 条" 是格式化字符串，花括号内会换成当前值。

为什么返回完整的 document 而不只返回条数？后面做引用回答时，除了知道命中几条，还必须拿到标题与原文。为什么空查询返回 []？否则空字符串被视为包含在任何字符串中，可能把全部资料误认为命中。这里的查找仍然是文字包含，不是语义检索，也不是 AI。

五、排错和完成检查（110–120 分钟）

现象 先检查什么
FileNotFoundError functions_manual.py 与 documents.json 是否在同一文件夹
NameError: name 'results' is not defined 是否在使用 results 之前调用了 find_documents
TypeError 出现在 append results 是否写成 []，而不是数字 0
输入 usb 找不到 查询与待查文字是否都转成小写
输出 1条 而非 1 条 检查 print 的拼接方式；两种只差显示空格，不影响命中
