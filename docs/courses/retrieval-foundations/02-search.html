七、报错与完成检查（115–120 分钟）

报错或现象 检查方法
FileNotFoundError JSON 与 .py 是否在同一目录？JSON 是否误存成 .json.txt？
JSONDecodeError 看行号，检查双引号、多余逗号和括号；JSON 不能有 documents =
UnicodeDecodeError 用编辑器另存为 UTF-8，保留原文件备份
AssertionError 对照真实数量和预期值，不要直接删除检查
修改后输出没变化 保存文件，确认改的是程序旁边的 JSON

完成标准：你能独立保存合法 JSON、读取三条资料、把它扩展为四条并同步验收条件。下一课会读取这四条说明，逐条显示并按关键词查找。
