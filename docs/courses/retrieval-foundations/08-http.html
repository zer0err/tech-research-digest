网络基础路线 · Python 3.12 · 预计 120 分钟 · 只访问本机

模型 API 本质上是 HTTP 服务。本课不访问任何外部网站：先在 127.0.0.1 启动一个一次性假接口，再由客户端发送 JSON。你会看到状态码、请求头、请求体与响应，并学习密钥为什么只能放在服务端环境变量。

一、四个概念（0–20 分钟）

  • URL：服务地址；本课是 http://127.0.0.1:8766/respond。
  • 方法：本课用 POST，表示提交数据。
  • 请求/响应 JSON：程序之间交换的结构化文字。
  • 状态码：200 表示成功；400 表示请求有问题；401 常用于认证失败；429 常用于限额；500 级表示服务端失败。

127.0.0.1 只指当前电脑。它不是互联网地址。本课假接口不会调用模型，也不会产生 API 费用。

这段代码首次使用“类”。class Handler(BaseHTTPRequestHandler) 表示在 Python 自带请求处理器上补充自己的行为；do_POST 是收到 POST 时会自动调用的方法，相当于放在类里的函数。self 指这一次处理请求的对象，self.headers 是收到的请求头，self.rfile 读请求体，self.wfile 写响应体。你不必现在自己设计一套类，只要能沿着“读输入 → 校验 → 写输出”找到对应行。

六、排错与验收（110–120 分钟）

现象 修正
Address already in use 上一次服务仍运行；停止它，或确认后改用未占用端口
Connection refused 先启动服务；它每次只处理一个请求
400 invalid json 确认请求体经过 json.dumps 并用 UTF-8 编码
密钥出现在输出 立即撤销真实密钥；状态检查只显示“已设置/未设置”
想关闭 TLS 检查 不要；本课 HTTP 仅限 127.0.0.1，真实外部 API 必须使用 HTTPS

完成标准：成功请求两行精确一致；404 与连接错误能区分；环境变量检查不泄漏值。下一课才安装模型 SDK，并继续保留离线测试路径。
