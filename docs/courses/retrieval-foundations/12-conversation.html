AI 应用路线 · Python 3.12 · 预计 120 分钟 · 离线完成

多轮对话不是把所有聊天无限拼接。历史越长，费用和延迟通常越高，也更容易把旧的错误带进新问题。今天实现一个固定容量的对话窗口，只保留最近三轮，并明确不保存密钥和原始系统环境。

字符数不是 token 数，不能拿它精确计算费用；它只是一个可重复的本地防护，避免意外把无限文本拼进请求。生产应用应使用服务商提供的 token 计数与上下文限制。

五、排错与验收（110–120 分钟）

问题 检查
两个会话互相出现内容 是否错误地把 turns=[] 作为共享默认值或用了全局列表

限长后长度多一位 省略号也占一个字符

完成标准：窗口移动输出一致；两个对话三项均为 True；能解释“轮数限制”“字符限制”和“服务商 token 限制”不是一回事。
