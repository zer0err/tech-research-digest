六、排错与验收（110–120 分钟）

现象 修正
No module named manual_assistant 检查 src/manual_assistant/__init__.py 与 pyproject 的 packages 路径
lockfile 被改写 你可能运行了更新命令；恢复后用 sync --locked 验证
复制项目后仍使用旧环境 不复制 .venv，在新目录重新 sync
pytest 版本不一致 查看 uv.lock，不要只看 pyproject 的文字

完成标准：原目录和干净复制目录均为 3 passed；能解释 pyproject 声明范围、uv.lock 精确解析和 .venv 本机环境的区别。下一课用本机 HTTP 服务理解网络请求与密钥边界。
