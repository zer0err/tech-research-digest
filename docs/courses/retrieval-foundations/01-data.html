代码 含义
documents = [ 建立列表，列表可以按顺序装多张信息卡

十、报错时按这张表排查

先看错误信息最后一行，然后回到对应的文件和行号。修改后保存，再运行同一条命令。

看到的提示 常见原因 怎么修
uv: command not found 或 uv 无法识别 终端尚未读到新路径 安装后重新开终端，核对官方安装输出
can't open file 目录不对，或文件实际叫 .py.txt 用 macOS 的 pwd、ls 或 Windows 的 Get-Location、dir 查看路径和文件
SyntaxError 弯引号、中文标点、缺逗号或括号 对照完整代码，用英文符号，核对成对括号
NameError documents 拼错或使用前未赋值 统一名字，保留前面的列表定义
KeyError: 'title' 字段名拼写不一致 检查是否写成 Title 或漏了 title 字段
IndexError 只有两条却取 [2] 完成第三条后再取下标 2
AssertionError 实际数量或标题不符合练习要求 核对三条资料和练习 A 的改名
TypeError 用加号拼接数字与文字 参考示例用 print("数量", len(documents))

如果窗口提示符变成 >>>，说明你进入了 Python 交互窗口。输入 exit() 回车，回到终端后再输入 uv run ...，不要把终端命令写在 >>> 后面。
