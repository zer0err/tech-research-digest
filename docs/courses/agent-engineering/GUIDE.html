已确认的硬件路线：本地 CPU/Mac 优先

  1. 所有人先使用Python3.12标准库完成离线控制器、数据与评测实验，不下载大权重，不需要GPU。
  2. Intel Mac以CPU为基线；Apple Silicon可评估Metal/MLX，但MLX不是Intel Mac通用后端。PyTorch的MPS必须检测可用性，不能因为系统叫macOS就自动判为可用。
  3. 本地生成优先评估llama.cpp兼容模型与量化格式。先登记架构、模型许可、实际可用内存、上下文和后端，再选择规模；不承诺某参数量在所有Mac都能运行。量化权重大小不等于运行内存。
  4. BERT/GPT-2先做极小样本机制验证。CPU训练很慢或模型下载受限时，不让它阻断Agent主线；随机初始化模型跑通不等于预训练中文能力验证。
  5. CUDA/QLoRA配方不能直接复制到Mac。Apple Silicon上的MLX-LM微调另设选修实现，需单独验证模型支持、数据格式与评测，不冒称等同已执行LlamaFactory CUDA配方。
  6. LlamaFactory/XTuner多GPU、分布式vLLM与大规模蒸馏保留为选修实验设计。默认不租云GPU、不要求Mac完成CUDA或多卡实训。
  7. Dify/RAGFlow等平台需独立测资源；低代码不等于轻量。资源不足时沿用标准库与单一轻量框架，不同时启动全部服务。
  8. 基础实验不自动完成框架实训；主线成果与GPU选修成果分开记录。

加速后端参考待进一步核验：PyTorch MPS文档与MLX-LM维护者仓库。当前未安装或运行这些后端，不宣称实测性能。
