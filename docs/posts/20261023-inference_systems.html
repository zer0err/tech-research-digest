RESEARCH BRIEF · 推理引擎、编译器与嵌入式系统

推理引擎、编译器与嵌入式系统简报（2026-10-23）

本期结论

  1. 缓存管理与逻辑寻址能显著提升 LLM 与 VLM 的推理吞吐量与预填延迟。

    • UlaCache 通过统一逻辑地址空间与 PB‑LRU 机制，在 H200 上实现 DP 1.16×、TP 1.70× 的速度提升；在 B300 上实现 DP 1.73×、TP 2.51× 的提升【1】。
    • VisMemo 通过熵感知的近似 KV 缓存重用，将缓存命中率从 27.78% 提升至 61.45%，并在 8K 视觉令牌下将预填延迟降低 48.3%【2】。
    • 两项工作均提供方法、实验数据与定量结果，构成趋势。

  2. 跨调用流水线协同与状态复用可在多种硬件平台上实现数倍加速。

    • FLASHRT‑PAI 在 RTX 5090 与 Jetson AGX Thor 上，匹配 16‑bit 精度时比官方编译路径快 1.3–3.7×，与 eager 实现相比快 3.38–12.66×【5】。
    • Difflet 在 AWS Trainium2 上，融合注意力加速 1.2–4.3×，驻留式推理比独立加载快 1.5–3.4×【6】。
    • 两项工作均提供完整方法与定量结果，构成趋势。

  3. 模型蒸馏可在保持或提升性能的同时大幅降低参数量与推理成本。

    • 通过对 HuBERT、data2vec 与 WavLM 的两层特征提取器蒸馏，模型仅占原 CNN 的 3% MAC，整体推理时间下降 20%【4】。
    • GridFM 通过 32.5× 参数压缩与消息传递深度减半，学生模型在可行性与反应功率分配上均优于教师【7】。
    • 两项工作均提供方法与实验结果，构成趋势。
