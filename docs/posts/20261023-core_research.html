多模态感知、音视频与人机交互（2026-10-23）

本期结论

  1. 通过为生成式代理提供物理可行性验证工具，BrickWright 能将物理有效率从 9%–69% 提升至 100%[1]，表明单模态（文本/图像）与物理约束的融合能显著提升多模态生成质量。
  2. Gate3DGen 的选择性预处理在合成基准上将 TRELLIS.2 网格距离降低 61.5%[2]，说明在单模态 3D 生成任务中，先行的图像清洗与多模态（视觉+几何）协同可显著提升结果精度。
  3. OmniRay 通过分层光线场表示实现了无相机依赖的单目 3D 重建，实验表明其在多种相机配置下均优于现有方法[3]，提示视觉与相机几何信息的多模态融合可实现更鲁棒的实时感知。

[1] BrickWright 通过 BrickLayer API 与物理验证器，使文本/图像提示下的 LEGO 组装生成物理可行的结构 预训练代理 + Python 工具包；验证器提供碰撞/漂浮反馈 100% 物理有效率（512 例）[1]；相较基线提升 9%–69%[1] 仅在 LEGO 砖块域验证；未评估更复杂物理场景；证据等级 A
[2] Gate3DGen 选择性预处理模型，自动决定是否对输入图像进行去噪/去模糊，保持 3D 生成所需视觉特征 退化感知路由 + 3D 定向一阶净化器；合成数据引擎生成清洁/退化对 合成基准 TRELLIS.2 距离下降 61.5%[2]；VLM 与人类偏好验证身份保留[2] 仅在合成与部分真实照片上测试；未公开真实世界大规模评估；证据等级 A
[3] OmniRay 通过三层光线场（径向基、球谐残差、自由形残差）实现相机无关单目 3D 重建 单图像输入 → 预测光线方向与尺度；无相机信息推断 3D 点云 在多相机配置实验中超越现有方法[3] 仅针对单目视觉；未涉及音频/雷达等多模态；证据等级 A

工程行动建议

  • 验证实验
    • 对 BrickWright，构建非 LEGO 物体（如木块、金属件）组装任务，评估物理有效率与提示遵循度。
    • 对 Gate3DGen，收集多光照、运动模糊、遮挡严重的真实照片，测量 3D 重建误差与视觉保真度。
    • 对 OmniRay，部署在移动设备摄像头（广角、鱼眼）上，评估实时性（帧率）与重建精度。
  • 落地评估
    • 在工业装配线上测试 BrickWright 生成的物理模型与实际装配误差。
    • 在无人机视觉导航中使用 Gate3DGen 预处理后 3D 地图，比较路径规划误差。
    • 在 AR/VR 头显中集成 OmniRay，评估用户体验与渲染延迟。
  • 后续跟踪指标
    • 物理有效率、提示遵循度、3D 重建误差（Chamfer/IoU）、实时帧率、用户满意度。
    • 对多模态融合的鲁棒性进行跨场景（光照、遮挡、相机类型）对比。
