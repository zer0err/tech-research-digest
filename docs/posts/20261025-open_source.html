本期要点

  • Ollama 0.40.11 新增 macOS 上的语音生成能力，支持 ollama run 直接朗读文本或模型回复，并可通过 /v1/audio/speech 接口流式输出音频。[1]
  • 新增 d3 决策模型系列（2B、4B、9B、27B），可对文本、结构化状态或图像进行分类、二元判断或概率评分。[1]
  • 该版本未包含对现有模型兼容性或性能的显著改动，主要聚焦功能扩展。[1]

逐项速览

变更 证据 局限
语音生成 发行说明中提到 “Ollama can now generate speech on macOS” 及示例命令 ollama run phonon "Hello from Ollama."，并说明可通过 /v1/audio/speech 接口流式音频。[1] 仅在 macOS 上可用；未说明对 Linux/Windows 的支持或性能指标。
d3 决策模型 说明中列出 “d3 brings vLLM Semantic Router's decision models to Ollama” 并给出模型尺寸与使用示例 ollama run d3 "A customer says their card was charged twice." --ask "Is this a billing issue?"。[1] 未提供模型准确率、推理延迟或与旧版模型的兼容性信息。
贡献者更新 记录了 @SynapShift 的首次贡献及完整变更日志链接。[1] 与功能无直接关联，属于版本记录。

值得采取的行动

  • 若需在 macOS 环境中实现文本转语音功能，可直接使用 ollama run phonon 或 /v1/audio/speech 接口进行测试。
  • 如计划使用决策模型进行业务分类，可先在本地实验 d3 2B/4B 版本，评估其推理速度与准确性。
  • 关注后续版本是否扩展至其他操作系统或提供性能基准，以便评估迁移风险。
