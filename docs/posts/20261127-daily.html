领域简报

基础模型与能力

本期结论

  1. Pathology foundation models在细胞身份捕捉上优于自然图像模型，BioScore指标显示所有病理模型得分均高于自然图像模型（0.299–0.371 vs 0.214–0.232）[1]。
  2. GeoFMs在海事领域可实现高精度船舶检测，使用压缩潜在空间表示的线性/非线性探测器在Sentinel‑1 GRD图像上实现ROC‑AUC 0.95的检测性能[2]。
  3. GeoFMs在船舶定位与类型识别上仍受限，定位误差约300 m，AIS类型码分类准确率仅62%，且与船舶长度高度相关[2]。
  4. BioScore提供无监督细胞身份评估框架，可在仅少量切片数据下对编码器进行分组与细胞身份匹配，且不需人工标签[1]。
  5. GeoFMs的潜在空间表示可缓解数据重力瓶颈，直接在压缩表示上操作避免了原始SAR图像的高存储与传输成本[2]。

领域简报

训练方法与数据

本期结论

  1. DART 通过重新利用被拒绝的推理轨迹，可在相同生成量下提升 37% 的 DeepMath‑103K 题目覆盖率，并将每个被接受轨迹的成本降低 30%[1]。
  2. MoLT‑KV 在 400B‑token 预训练中实现 1.7 倍的验证交叉熵（CE）标记效率，并在 3B MoE 模型上提升 10‑域困惑度 0.75 与 10‑任务准确率 2.1pp[2]。
  3. DART 生成的轨迹在 Llama‑3.1‑8B‑Instruct 上，在 MATH‑500 与 AIME 评估中获得五项中最高点估计，表明其后训练数据对数学推理性能有显著正面影响[1]。
  4. MoLT‑KV 通过“循环 KV”机制消除同位点跨循环依赖，并结合循环强制实现单遍 Mixture‑of‑Loops（MoL）解码，突破训练循环视界，但其在实际推理速度与硬件资源占用方面的具体数值未在摘要中给出[2]。
