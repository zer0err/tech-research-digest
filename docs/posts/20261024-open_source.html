本期要点

  • Ollama 发布了 v0.40.10 版本，新增 NVIDIA Nemotron 3.5 Bolt E4B 模型，该模型基于 Gemma 4，支持 128K‑token 上下文窗口并加入 DFlash 预估解码功能。[1]
  • 新模型定位为“小型视觉‑语言模型”，旨在实现快速本地对话、图像理解与工具调用，但官方未提供性能基准或兼容性测试结果。[1]
  • 发行说明仅列出模型新增与变更的“完整变更日志”，未包含对现有模型或 API 的迁移风险评估。[1]
  • 该版本的发布未伴随正式的发布说明或兼容性声明，用户需自行验证与现有工作流的兼容性与性能差异。[1]
