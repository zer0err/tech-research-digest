AI 开源项目与工具更新（2026-10-23）

依据公开来源自动整理，请核对证据边界。

本期要点

  • v0.40.9 引入 Phonon 语音合成（Apple Silicon）与 d3 决策模型，并在 Linux/Windows 上正式支持 Flint。
  • v0.40.9 对流式 OpenAI/Anthropic 请求错误处理、上下文长度传递以及 Web‑search 思考设置做了关键修复。
  • v0.40.8 发布 Recursive Flint：40 B 参数混合专家模型，支持 262 K‑token 上下文窗口，已在 Terminal‑Bench 2.1 与 SWE‑bench Verified 上分别达 54.9 % 与 74.2 % 的分数。
  • 预发布版本（rc3/rc2/rc1）已完成 Phonon checkpoint 迁移、Flint 思考逻辑修复与 llama.cpp 更新，但仍为 prerelease，非正式发布。

值得采取的行动

  1. 验证 Phonon 语音合成：在 Apple Silicon 机器上执行 ollama run phonon "Hello from Ollama." 并通过 /v1/audio/speech 端点进行集成测试。
  2. 评估 d3 决策模型：在本地或云环境中对业务场景（如客服票据分类）进行基准测试，记录准确率与推理时延。
  3. 迁移 Flint 至 Linux/Windows：在目标操作系统上安装 v0.40.9，确认 Flint 能正常启动并执行代码分析任务。
  4. 监控流式请求错误：在生产环境中开启日志捕获，验证 OpenAI/Anthropic 流式请求失败是否被正确报告。
  5. 尝试 Recursive Flint：在包含多文件代码库的项目中使用 ollama run flint，观察 262 K‑token 上下文窗口对调试与功能实现的影响。
  6. 关注后续 GPU 支持：跟踪 v0.40.9 及 v0.40.8 之后的发布说明，及时获取 Linux/Windows GPU 支持信息。
