本期要点

  • Hugging Face Transformers v5.22.2 主要修复安全与分布式问题，改进 NCCL 设备 ID 处理与 Jinja 沙箱安全性[1]。
  • Ollama v0.40.15 新增对 Xiaomi MiMo V2.6 9B 代码模型与 AutoTrust 决策模型的支持，并开启 Apple Silicon 上的 AutoTrust 运行[2]。
  • Ollama 0.40.15 对 Kimi Code CLI 迁移、Pi 模型列表自动填充、复用 Recurrent 与 Vision GGUF 模型以及 Qwen3/Qwen3.5 长上下文扩展提供兼容性改进[2]。
  • 两个项目均未发布重大 API 变更，现有代码库可直接升级，迁移风险低[1][2]。
