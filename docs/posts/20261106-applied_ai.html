智能硬件产品化、可靠性与安全（2026-11-06）

本期结论

  1. 主动故障诊断可通过理论保证的辅助控制实现：论文[1]提出的递归窗口 FDI 框架在数值测试中显示了对候选故障模式的概率估计与触发机制的有效性，且辅助控制设计在保持飞行操作最小干扰的同时保证了 FDI 效果[1]。
  2. LLM 在水下机器人高层操作支持中有潜在价值，但缺乏可预测性：摘要[2]指出 LLM 可用于故障诊断、遥测解释和任务调整，但目前在 grounding、consistency 与 causal reasoning 上仍不足以直接控制系统，建议将其作为辅助层而非主控层[2]。
  3. 智能硬件在教育与文化领域的 IoT 监测可显著提升警报覆盖率：论文[3]的模拟显示，三传感器共识规则在遗产画廊中将异常检测率提升至 98.0%，且误报率降至 0.7/30 天，表明多传感器融合在安全监测中的有效性[3]。

工程行动建议

  1. 验证实验

    • 对[1]中的递归窗口 FDI 方案，在实际嵌入式飞行控制板上实现并测量故障检测延迟与误报率。
    • 在水下机器人平台上搭建 LLM 辅助层，记录其对故障诊断与任务调整的响应时间与准确性。
    • 在教育/文化场景的 IoT 监测硬件上部署 3 传感器共识规则，采集真实环境数据验证误报率。

  2. 落地评估

    • 评估 FDI 方案对飞行系统功耗与热管理的影响，确保辅助控制不引入显著功耗。
    • 对 LLM 辅助层进行可解释性与安全性评估，确保其输出可被人工操作员快速验证。
    • 对 IoT 监测系统进行合规性测试（如 ISO/IEC 27001），验证数据安全与隐私保护。

  3. 后续跟踪指标

    • FDI 方案：故障检测率、误报率、平均恢复时间、功耗增量。
    • LLM 辅助层：响应时间、误判率、操作员满意度。
    • IoT 监测：异常检测率、误报率、系统能耗、数据保留周期。
