RESEARCH BRIEF · 高效 AI、模型压缩与端侧适配

高效 AI、模型压缩与端侧适配简报（2026-10-23）

本期结论

  • 蒸馏与轻量化：APED‑CXR [3] 与 CORD [1] 均表明，蒸馏技术可在保持或提升性能的同时显著降低模型参数量（APED‑CXR 11.1 M 参数）。
  • 压缩技术提升效率：SAKURA [4] 与 GR‑GIC [5] 均通过压缩模型状态（KV 缓存或量化潜在向量）实现显著的延迟与存储节省（SAKURA 延迟降低 1.82×/3.27×，缓存压缩 3.06×；GR‑GIC 编码/解码时间 4.60/5.98 ms）。
  • 专家剪枝的潜力：SPARE [6] 在 50 % 专家剪枝下提升准确率，提示路由熵驱动的稀疏分配可在高剪枝率下保持性能，但缺乏资源消耗数据，仍为值得关注的信号。
  • 量化与公平性：Qwen3、Gemma‑3、SmolLM2 的量化实验 [7] 显示，压缩模型时偏见与回避的关系复杂，需同时评估两者，亦为值得关注的信号。

逐项分析

[1] CORD: Conflict-Aware Optimization for Joint RL and Distillation in Agents

  • 核心贡献：提出冲突感知优化框架 CORD，解决 RL 与自蒸馏梯度冲突。
  • 方法与数据：在三种联合训练方案中使用 CORD，采用梯度投影与最近点闭式更新。
  • 性能证据：ALFWorld 成功率提升 1.5–15.9 %；WebShop SDAR 从 60.7 % 提升至 64.6 %。
  • 局限与证据等级：缺乏对梯度冲突机制的定量分析；证据等级 A。
  • 工程意义：可直接集成到现有 RL+蒸馏训练流程，提升训练稳定性与最终性能。

[2] Compression Formula for Nonattacking Fillings of Non-symmetric Macdonald Polynomials

  • 核心贡献：提出非对称 Macdonald 多项式的压缩非攻击填充模型。
  • 方法与数据：构造多行队列模型，证明对大类弱组合成立。
  • 性能证据：无实验数据。
  • 局限与证据等级：缺乏实验验证；证据等级 C。
  • 工程意义：理论性研究，对 AI 模型压缩无直接工程价值。

[3] APED-CXR: Adaptive Privileged Evidence Distillation for Chest X‑Ray Grounding with Image‑Only Inference

  • 核心贡献：通过报告信息蒸馏实现仅图像推理的胸片定位模型。
  • 方法与数据：冻结多模态教师，学生 11.1 M 参数，使用报告支持分数作为训练目标。
  • 性能证据：PadChest‑GR 上 box‑level F1 从 0.302 提升至 0.338；NIH ChestX‑ray14 上 box recall 从 0.423 提升至 0.447；诊断 AUC 保持不变。
  • 局限与证据等级：缺乏推理延迟、功耗等指标；证据等级 A。
  • 工程意义：适用于移动端胸片诊断，显著降低模型体积并保持定位性能。

[4] SAKURA: Serving Attention Key‑Value State Under Rate Adaptation for Private Image Editing on Phones

  • 核心贡献：云端‑边缘架构下的 KV 状态压缩与自适应缓存选择。
  • 方法与数据：基于 token‑importance 的压缩，动态选择缓存表示，流水线运行。
  • 性能证据：在 Snapdragon 8 Elite Gen 5 上，SAKURA 对比 CacheGen（DiT）和纯设备生成，延迟分别降低 1.82× 与 3.27×；缓存存储比未压缩缓存低 3.06×。
  • 局限与证据等级：未给出功耗、吞吐等指标；证据等级 A。
  • 工程意义：实现手机端隐私友好图像编辑，显著降低网络带宽与存储需求。

[5] Efficient Generative Image Compression with Quantized Latents Refinement

  • 核心贡献：提出 Guided Refinement 与 reorganized P‑RVQ 的 GIC 方法。
  • 方法与数据：在 Kodak 数据集上评估，使用 NVIDIA A100 与 Jetson Orin NX。
  • 性能证据：BD‑rate 在 LPIPS、DISTS、PSNR、FID 上分别节省 23.19%、37.71%、22.30%、22.14%；编码/解码时间 4.60/5.98 ms；在 Jetson Orin NX 上延迟与轻量 GIC 相当。
  • 局限与证据等级：未给出功耗、内存占用；证据等级 A。
  • 工程意义：在低比特率下兼顾感知质量与推理速度，适合边缘压缩应用。

[6] SPARE: Sparsity Allocation via Routing Entropy for Efficient MoEs

  • 核心贡献：基于路由熵的训练无关稀疏分配方法。
  • 方法与数据：对 Mixtral、Qwen3、DeepSeek 进行实验，采用 50 % 专家剪枝。
  • 性能证据：Qwen3‑30B‑A3B 八任务平均从 57.2 % 提升至 63.8 %；DeepSeek‑R1 在数学、代码、科学平均从 80.1 % 提升至 82.8 %。
  • 局限与证据等级：缺乏对内存、延迟等资源指标的评估；证据等级 A。
