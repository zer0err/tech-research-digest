AI 芯片、计算架构与硬件平台（2026-11-16）

本期结论

  1. 混合精度阵列在点云网络加速中能显著提升吞吐与能效。PQuant 通过 Morton‑code 细粒度量化与可重构混合精度 systolic array，实现点基网络 3.7×、体素网络 3.5× 的速度提升，并分别获得 5.2× 与 6.0× 的能耗下降[1]。
  2. 自由形态映射可突破传统模板限制，提升 Wafer‑Scale 计算单元利用率。WaferTetris 在 Cerebras WSE‑3 上对 LLM 解码实现最高 4.42× 的系统吞吐提升，且在科学 stencil 基准上亦表现出更高的可用内存容量[2]。
  3. 推理时学习（ITL）与推理加速器的协同可在保持低延迟的同时实现模型自适应。LWS 架构通过共享矩阵计算资源与权重版本控制，将学习与预测并行化，理论上可在推理过程中隐藏学习开销[3]。

逐项分析

资料 核心贡献 方法与数据 性能证据 局限与证据等级 工程意义
[1] PQuant 通过 Morton‑code 细粒度量化与可重构混合精度阵列加速点云网络 采用 Morton‑code 捕获点相似性，将特征分解为基准与偏移；对体素网络使用高精度远程体素、低精度近距离体素；实现可重构混合精度 systolic array 速度提升 3.7×（点基）/3.5×（体素基）；能耗降低 5.2×/6.0× 相比 PointAcc[1] 仅在实验平台上验证，缺乏不同点云数据集与硬件实现细节；未给出面积与制程信息[1] 对点云推理硬件设计提供可行的量化与阵列重构思路，适用于需要低功耗高吞吐的 3D 视觉应用。
[2] WaferTetris 通过自由形态映射提升 Wafer‑Scale 加速器利用率 Tetris‑like 计算打包、递归吞吐模型、每色门控架构；利用 FPGA place‑and‑route 算法满足 WSE 路由约束[2] LLM 解码吞吐提升 4.42×；科学 stencil 基准提升可用内存容量[2] 仅在 Cerebras WSE‑3 上评估，缺乏对不同规模与任务的泛化；未提供面积/功耗数据[2] 为大规模加速器提供更灵活的映射策略，可在保持代码兼容的前提下提升资源利用。
[3] Mutable Inference / LWS 将学习与推理共享硬件，支持推理时学习 通过权重版本控制、可恢复的 reduction block、专用 softmax‑gradient 单元实现学习与预测并行[3] 仅在模型化的 datacenter 与 edge NPU 上给出理论隐藏学习开销的结果[3] 仅为模型化结果，缺乏实测验证；未给出面积、功耗与延迟指标[3] 为需要在线自适应的 LLM 推理场景提供硬件架构方向，可能降低整体系统成本。

工程行动建议

目标 验证实验 落地评估 后续跟踪指标
PQuant 在目标 FPGA/ASIC 上实现 Morton‑code 量化模块与混合精度 systolic array，测量点云网络（如 PointNet++、VoxelNet）在不同数据集上的吞吐与能耗 对比现有 PointAcc 或通用 GPU 实现，评估面积与制程差异 量化精度对模型精度的影响、功耗/面积比例、对不同点云密度的鲁棒性
WaferTetris 在可用的 Wafer‑Scale 设备（如 Cerebras WSE‑3）上部署 Tetris‑like 映射，记录 PE 利用率、内存占用与延迟 与模板映射基线在多任务（LLM、科学计算）下比较吞吐与能耗 PE 利用率提升幅度、可用内存比例、映射时间与编译复杂度
Mutable Inference / LWS 在 FPGA/ASIC 上实现权重版本控制与共享矩阵计算，测量推理时学习对延迟与精度的影响 在边缘与数据中心 NPU 上评估整体功耗与面积 学习与预测的时间分配比例、模型精度漂移、硬件利用率

注意：上述实验均基于公开摘要所述方法与数据，缺乏完整实验细节与硬件实现信息，建议在实验前先行获取原始代码与硬件描述文件。
