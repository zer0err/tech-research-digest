本时段要点

  1. GitHub Copilot 的使用指标 API 现已支持 BYOK（Bring Your Own Key）使用统计，可将自托管模型与托管模型的使用分离 [1]。

逐项速览

  • BYOK 与企业自定义模型的使用 API
    GitHub 在 2026‑11‑03 发布的更新说明，Copilot 使用指标 API 现在能显示 BYOK 的使用情况，帮助企业区分自托管模型与 GitHub 托管模型的使用量。此功能对需要合规审计和成本核算的企业尤为重要 [1]。

  • Dependabot 对 Agent Package Manager 的支持
    该更新使 Dependabot 能够为 APM 生成版本更新 PR，保持 AI 代理相关依赖的最新状态，从而降低安全风险并提升功能可用性。此举表明 GitHub 正在将 AI 相关工具纳入其持续集成/持续交付（CI/CD）生态中 [2]。

  • Copilot 在 JetBrains Air 的集成
    JetBrains Air 通过 ACP 与 Copilot 对接，允许开发者在 IDE 内部委托编码任务、指导执行并审阅结果。此集成扩展了 Copilot 的使用场景，提升了开发效率，尤其适用于需要多语言或跨平台支持的项目 [3]。
