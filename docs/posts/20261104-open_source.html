AI 开源项目与工具更新（2026-11-04）

AI 分析：Groq

依据公开来源自动整理，请核对证据边界。

本期要点

  • ollama launch claude 现已将 Claude Code 的输出 token 限制应用到云模型，避免 128k 默认上限导致的截断问题 [1]。
  • /api/chat 的云端网页搜索响应已正确解码（含压缩），提升了 API 的可用性和可靠性 [1]。
  • OpenAI 兼容端点不再覆盖模型自带的采样默认值，未指定 temperature/top_p 时将使用模型自身设置，保持一致性 [1]。
  • /v1/responses 现在保留可读输入内容（包括先前的助手拒绝），避免信息被扁平化导致的上下文丢失 [1]。

逐项速览

变更 证据 局限
Claude Code token limit ollama launch claude 现在应用模型的输出 token 限制，云模型不再受 128k 默认上限约束 [1]。 仅适用于 Claude Code，其他模型仍按默认上限运行。
云搜索响应解码 /api/chat 的云端网页搜索响应已正确解码，包括压缩响应 [1]。 仅针对 /api/chat，其他端点未说明是否受影响。
OpenAI 兼容端点采样默认 OpenAI 兼容端点不再覆盖模型的采样默认值，未指定时使用模型自身值 [1]。 仍需手动设置 temperature/top_p 以获得可控输出。
/v1/responses 可读性 /v1/responses 现在保留可读输入内容，包括先前助手拒绝 [1]。 仅在 /v1/responses 端点，其他响应格式未提及。
ChatGPT 断连重试 Ollama 的 app 可重试 ChatGPT 断连失败，避免连接残留 [1]。 仅限 app，CLI 或 API 端点未说明。
codex 路由验证 ollama launch codex 在配置前验证 ChatGPT 路由，并在不可用时报告错误 [1]。 仅针对 codex，其他模型无此验证。
MLX top‑k 采样加速 在 MLX 上对大词表的 top‑k 采样速度提升 [1]。 仅适用于 MLX，其他后端未提及。

值得采取的行动

  • 在使用 Claude Code 的云模型时，确认已开启 token 限制功能，避免意外截断。
  • 对 /api/chat 的搜索功能进行回归测试，确保压缩响应能被正确解码。
  • 若依赖 OpenAI 兼容端点，请检查模型默认采样设置，必要时显式指定 temperature/top_p。
  • 在使用 /v1/responses 时，验证助手拒绝信息是否完整保留，以防上下文丢失。
  • 若使用 Ollama app 与 ChatGPT 集成，开启断连重试功能以提升稳定性。
