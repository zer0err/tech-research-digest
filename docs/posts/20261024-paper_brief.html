本期要点

  • Neuromorphic 方案在边缘 IoT 设备中显著降低功耗与延迟，典型平台如 Intel Loihi、IBM TrueNorth 与 BrainScaleS 在能耗与吞吐上各有优势[1]。
  • 传统 FPGA 通过 hls4ml 可实现时钟驱动的 SNN 推理，单次推理延迟约 34 µs，验证了 HLS 与 Vivado 合成的可行性[2]。
  • 光学 neuromorphic 架构 SEPhIA 采用多波长激光与微环调制器，单脉冲神经元比率 < 1，且在四分类任务上达 90 %+ 准确率，展示了光学实现的可扩展性与能效潜力[3]。

逐项速览

  1. Neuromorphic Edge 推理

    • 论文对 Loihi、TrueNorth 与 BrainScaleS 的学习架构、能耗、吞吐及边缘适用性进行了整体比较[1]。
    • 通过 Google Speech Commands 与 DVS Gesture 数据集的关键词识别与手势识别案例，验证了 SNN 在实时推理中的低功耗与低延迟特性。
    • 局限：摘要未给出具体功耗数值、吞吐率或面积/制程信息，无法量化不同平台的硬件成本。

  2. FPGA 上的 SNN 推理

    • hls4ml 扩展支持将 PyTorch 训练的量化 SNN 部署至 FPGA，示例为 Heidelberg Spiking Digits 数据集的密集量化 SNN[2]。
    • 推理延迟约 34 µs，已通过软件参考、HLS C 模拟、HLS 合成及 Vivado 合成报告验证。
    • 该工作未讨论功耗、面积或制程细节，亦未说明在更大规模网络上的可扩展性。

  3. 光学 SNN 架构 SEPhIA

    • 采用微环调制器与多波长激光实现单激光/神经元 < 1 的比率，强调实现可行性与真实规模化[3]。
    • 通过时间域共模拟与物理感知的可训练光电 SNN 模型，四分类任务准确率 > 90 %，与软件模型相近。
    • 设计空间研究量化了光学器件参数对 SNN 性能的影响，但摘要未给出具体功耗、延迟或面积数据，且未说明与传统 CMOS 或 FPGA 的直接对比。

值得采取的行动

  • 对比实验：在同一边缘任务（如关键词识别）上，分别使用 Loihi、TrueNorth 与 SEPhIA 进行功耗与延迟测量，填补摘要缺失的定量数据。
  • FPGA 规模化验证：在更大规模的 SNN（多层、更多神经元）上使用 hls4ml 进行合成与功耗评估，验证 34 µs 延迟是否可保持。
  • 光学与电子协同：探索 SEPhIA 与传统 FPGA 结合的混合架构，评估光学前端对整体功耗与面积的影响。
