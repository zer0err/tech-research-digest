逐项速览

  • 模型停用
    GitHub 官方公告指出，12 月 14 日起将停用一系列 Copilot 模型。停用将影响所有 Copilot 体验，包括 Chat、inline edits、ask、agent 以及代码补全等。此举可能导致现有依赖这些模型的工作流出现中断，需要开发者提前迁移或调整模型使用。 [1]

  • GHES 支持
    Copilot App 新增了对 GitHub Enterprise Server 的支持，用户可将 GHES 账号添加至 Copilot App，以便在企业内部仓库、issues 与 PR 上使用 Copilot。此功能扩展了 Copilot 在企业私有环境中的可用性，降低了对公共 GitHub 的依赖。 [2]

  • Gemini 4 Hydrogen 上线
    Gemini 4 Hydrogen 已在 Copilot 中正式发布，定位为快速、高效的代理式编码模型。其特点包括更佳的指令理解、工具调用与多步工作流支持，旨在提升编码效率。此更新标志着 Copilot 与 Google AI 技术的进一步深度融合。 [3]
