逐项速览

1. Prior‑Informed Machine Learning (PIML)

  • 核心变化：将敏感度与特异度的优化目标直接嵌入 ML 训练流程，并通过贝叶斯推理融合临床先验[1]。
  • 证据：在宫颈癌、口腔高危病变和早产检测三大临床域中，PIML 与传统 ML 相比表现更佳，且与知识驱动方法竞争或优于[1]。
  • 局限：摘要未提供具体数值或对比基准，无法评估提升幅度；未说明模型在不同硬件上的可复现性与部署成本[1]。

2. MoE 推理加速（NVIDIA DGX Spark）

  • 核心变化：通过三种策略（批量大小优化、张量并行、混合精度）提升 Ling‑3.0‑flash 的推理吞吐量[2]。
  • 证据：博客指出在 batch‑size‑1 评估中，识别性能瓶颈后实施上述优化可显著加速，但未给出具体速度提升百分比[2]。
  • 局限：缺乏实验细节（如基准模型、硬件配置、测量方法），无法复现或量化加速效果[2]。

3. 量化边缘推理（Self‑Supervised SAR‑Optical Encoder）

  • 核心变化：在三种 commodity x86 芯片上对预训练的 SAR‑Optical masked‑autoencoder 进行 FP32/FP16/INT8 推理，并测量延迟、能耗与线性探针精度[3]。
  • 证据：INT8 量化仅使 micro‑mAP 变动 +0.0006，属于种子波动范围内，说明精度保持不变；同时 CPU 延迟下降 1.45×，能耗下降，VNNI 参考进一步提升 1.53×[3]。
  • 局限：未提供具体硬件型号、测量环境或对比基准；未说明量化对模型训练阶段的影响[3]。
