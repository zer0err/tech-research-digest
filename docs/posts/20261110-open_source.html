本期要点

  • Ollama 发布 v0.40.16，新增 Ripple Preview 65B 模型并改进 Qwen3.8 Flash 内存占用 [1]。
  • ollama launch 现支持自动路由 Claude Code 与云模型退役提示，提升迁移安全性 [1]。
  • API /v1/responses 与 /v1/models 的行为已修正，避免默认截断与空值返回，增强兼容性 [1]。
  • Windows ARM 上 CUDA 13.5 支持正式上线，扩展硬件兼容范围 [1]。

变更 证据 局限
